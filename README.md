# えいごクエスト 中継サーバー

9歳児向け英語学習アプリ「えいごクエスト」の発音採点機能を支える、中継サーバーです。

## これは何をするものか

スマホアプリが録音した音声を、直接 Azure AI Speech に送ると、Azureの「鍵（APIキー）」をアプリの中に書く必要があり、誰でも盗み見できてしまいます。

このサーバーを間に挟むことで：

1. アプリ → このサーバーに音声を送る（鍵不要）
2. このサーバー → Azureに音声を送って採点してもらう（鍵はここだけが知っている）
3. このサーバー → 結果をわかりやすい形でアプリに返す

という流れになり、鍵を安全に守ることができます。

## ファイル構成

- `api/pronunciation.js` … 発音採点のメイン処理
- `api/health.js` … サーバーが動いているか確認するためのテスト用ページ
- `package.json` … プロジェクトの基本情報

## デプロイ手順（Vercel）

1. このリポジトリをGitHubにアップロードする
2. [vercel.com](https://vercel.com) にアクセスし、GitHubアカウントでログイン
3. 「Add New」→「Project」から、このGitHubリポジトリを選択
4. デプロイ前の設定画面で「Environment Variables（環境変数）」に以下を追加：
   - `AZURE_SPEECH_KEY` … Azureポータルの「キーとエンドポイント」画面にある「キー1」
   - `AZURE_SPEECH_REGION` … `japaneast`
5. 「Deploy」をクリック
6. 数十秒〜数分でデプロイが完了し、URLが発行される（例：`https://eigoquest-relay.vercel.app`）

## 動作確認

デプロイ完了後、ブラウザで以下にアクセス：

```
https://（あなたのVercel URL）/api/health
```

`{"status":"ok", ...}` と表示されれば成功です。

## 注意

- `AZURE_SPEECH_KEY` は絶対にコードに直接書かず、必ず環境変数（Vercelの管理画面）から設定してください
- このリポジトリ自体は「公開（Public）」でも問題ありません。鍵はコードに含まれていないためです
